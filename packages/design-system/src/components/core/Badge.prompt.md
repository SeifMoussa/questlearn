Small status pill for mastery/risk state — used in Learner Spotlight, Learners Needing Support, class lists.

```tsx
<Badge tone="onTrack">On Track</Badge>
<Badge tone="atRisk">At Risk</Badge>
```

Tones map directly to the palette's semantic states: `onTrack` (green), `needsSupport` (amber), `atRisk` (red), `neutral` (gray), `brand` (indigo tint, e.g. "Most Popular").
